# 素材约定

## 目录

素材按画风、设计版本、类别和状态组织：

```text
assets/<setting>/<design-version>/<kind>/<variant>/<character-id>.<extension>
assets/bs2/v1/portraits/normal/deepseek.png
```

当前使用 `bs2/v1/portraits/normal`，表示 BLACK SOULS II 画风、第一版设计、常态立绘。

角色 ID 为 `gpt`、`gemini`、`deepseek`、`qwen`、`doubao`、`mimo`、`claude`、`glm`。Claude 的别名 Opus 保留在清单中。

## 扩展类别

| 目录 | 素材 |
| --- | --- |
| `expressions` | 表情、口型、局部替换 |
| `poses` | 新姿势、半身、头像 |
| `costumes` | 换装与其他造型 |
| `animations` | 动作、透明视频、序列帧 |
| `models` | 分层文件、绑定与模型 |
| `voices` | 配音与声线样本 |

[manifest.json](../manifest.json)记录角色、文件路径和尺寸。新造型或状态使用新路径，设计更新时增加版本号。
