# 使用说明

## 文件

- 第一版8张常态稿：`assets/bs2/v1/portraits/normal/`。
- 古兰篇基础稿：`assets/bs2/v2/portraits/normal/`。
- 本期关键反应：`assets/bs2/v2/expressions/<状态>/`。
- 本期弧光动作与抱头版：`assets/bs2/v2/poses/<状态>/`。

原图均为1024×1536 RGBA透明PNG。差分是完整人物图，切换时按脸部和身体位置对齐；部分图片的透明留白不同。预览JPEG用于查看，剪辑请取PNG。

古兰篇增量包包含26张PNG，以及使用说明、素材清单、CREDITS和LICENSE。MiniMax是早期试跑花絮角色，Grok抱头版是额外的夸张反应。
