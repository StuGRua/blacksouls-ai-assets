# 使用说明

## 导入

常态立绘在 [`assets/bs2/v1/portraits/normal/`](../assets/bs2/v1/portraits/normal/)。选择角色对应的透明 PNG，直接导入剪辑软件、图像编辑器或游戏引擎，可按需要裁切或缩放。
