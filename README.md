# BLACK SOULS 系列 AI 拟人素材

BLACK SOULS 系列的 AI 拟人素材库，收录 8 个角色的 BLACK SOULS II 风格常态立绘，由 AI 辅助重绘。

所有立绘均为 **1024×1536、RGBA、透明背景 PNG**，可直接导入剪辑软件、图像编辑器或游戏引擎。
